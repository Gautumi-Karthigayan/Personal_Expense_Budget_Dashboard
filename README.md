# Personal Expense & Budget Dashboard

A simple responsive web application based on the Excel dashboard.

## Features
- Add expenses with date, description, category, payment mode, amount, and Need/Want.
- Automatic Total Expense, Total Needs, Total Wants, and Budget Remaining.
- Expense by Category chart.
- Needs vs Wants chart.
- Payment Mode chart.
- Expense history with delete.
- Export expense history to CSV.
- Data and monthly budget are saved in the browser using localStorage.

## Run
Open `index.html` in a modern browser.

No installation or backend is required for the basic version.
